# 명언 배경화면

고른 명언을 폰 배경화면(홈·잠금 화면)에 띄워주는 안드로이드 앱.

## 1차 버전 기능
- 추천 명언 목록 (원작자 표시) + 내 명언함 (직접 쓰기·삭제)
- 분야(공부·일·효율·인생)별 / 전체 랜덤
- 명언 종류 필터: 전체 / 유명인 명언만 / 내 명언만
- 명언 검색
- 원하는 명언을 골라 바로 배경화면으로 설정
- 1시간 ~ 하루 주기로 자동 변경
